================================================================================
PERFORMANCE & LIMITS
================================================================================

Rate Limiting:
  - Max conversions per minute per IP: 20
  - Adjustable via server configuration

File Limits:
  - Max file size: 100MB
  - Max batch files: 100 files per request
  - File expiration: 1 hour (3600 seconds)

Processing Times (Average):
  - Markdown→HTML: ~17ms
  - CSV→JSON: ~30ms
  - Image→WebP: ~100ms
  - PDF→Image (single page): ~50ms
  - Batch ZIP creation: <100ms

Storage:
  - Database size for 1000 records: ~500KB
  - Conversion files: In-memory (auto-cleanup)
  - Database: SQLite with auto-expiration
