## 🏗️ TECHNICAL ARCHITECTURE

### Request Flow
```
User selects service & uploads file(s)
              ↓
Client sends FormData + tool_name via POST /api/convert
              ↓
Backend routes to execute_service_conversion()
              ↓
Service-specific handler function processes files
              ↓
Output file saved to temp directory
              ↓
Response JSON returned to frontend
              ↓
UI updates with success notification + adds to history
```
