## ⌨️ Keyboard Shortcuts (Feature 5)

```
Mac:
├─ Cmd+S  → Open settings panel
├─ Cmd+⏎  → Submit/convert
├─ Esc    → Close modals
├─ Cmd+1-5 → Jump to favorite tools
└─ ?      → Show shortcuts help

Windows/Linux:
├─ Ctrl+S  → Same as Mac
├─ Ctrl+⏎  → Same as Mac
├─ Esc     → Same as Mac
├─ Ctrl+1-5 → Jump to tools
└─ ?       → Help
```

## 📥 Download Management (Feature 13)

After conversion, see bottom-right panel:

```
✅ Download Ready
filename.pdf

[⬇️ Download] [✏️ Rename] [📁 Folder]
```

- **Download:** Save file now
- **Rename:** Change filename before saving
- **Folder:** Set preferred download location

## 📡 API Integration (Feature 15)

**Click 📡 API button to see:**

- Full API documentation
- Copy-paste ready cURL commands
- All endpoints and parameters
- Authentication guide
- Code examples in multiple languages

```
Example:
$ curl -X POST https://api.docpro.local/api/convert \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"file_url": "...", "target_format": "yaml"}'
```

**Just click [📋 Copy] button!**
