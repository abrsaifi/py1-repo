🔗 API Documentation

Use these endpoints to automate conversions in your applications.

📚 View Full API Docs
1️⃣ Upload & Convert
POST /api/convert Content-Type: application/json Authorization: Bearer YOUR_API_KEY { "file_url": "https://example.com/file.pdf", "target_format": "yaml", "quality": 85 }
2️⃣ Batch Processing
POST /api/batch-convert Content-Type: application/json { "files": [ {"url": "file1.pdf", "target": "yaml"}, {"url": "file2.docx", "target": "markdown"} ] }
⚙️ Common Parameters
quality
integer (0-100)
Output quality for lossy formats. Default: 85
target_format
string
Desired output format (pdf, yaml, markdown, jpeg, etc.)
page_range
string (optional)
Pages to extract: "1-10", "1,3,5", or "all"
💻 cURL Examples
curl -X POST https://api.docpro.local/api/convert \ -H "Authorization: Bearer YOUR_API_KEY" \ -H "Content-Type: application/json" \ -d '{ "file_url": "https://example.com/document.pdf", "target_format": "yaml" }' \ -o result.yaml
🔐 Authentication

All API requests require authentication. Include your API key in the Authorization header:

Authorization: Bearer sk_live_YOUR_API_KEY_HERE
