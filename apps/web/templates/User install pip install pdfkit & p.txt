Here's an overview of **pdfkit** from PyPI:

## Summary
**pdfkit** is a Python wrapper for the **wkhtmltopdf** utility that converts HTML to PDF using the Webkit rendering engine. It supports both Python 2 and 3.

## Installation
1. **Python package**: `pip install pdfkit`
2. **wkhtmltopdf binary** (required separately):
   - Linux/Debian: `sudo apt-get install wkhtmltopdf`
   - macOS: `brew install homebrew/cask/wkhtmltopdf`
   - Windows: Download from [wkhtmltopdf.org](http://wkhtmltopdf.org/)

## Basic Usage
```python
import pdfkit

# From URL
pdfkit.from_url('http://google.com', 'out.pdf')

# From HTML file
pdfkit.from_file('test.html', 'out.pdf')

# From HTML string
pdfkit.from_string('Hello!', 'out.pdf')

# Multiple files/URLs
pdfkit.from_url(['google.com', 'yandex.ru'], 'out.pdf')
```

## Key Features
- Convert HTML to PDF from URLs, files, or strings
- Customizable options (page size, margins, encoding, headers, footers, TOC, etc.)
- Return PDF as variable instead of saving to file
- Support for external CSS files
- Meta tag configuration in HTML
- Verbose output for debugging

## Important Notes
- **wkhtmltopdf must be installed separately** - pdfkit alone won't work
- Debian/Ubuntu repos have reduced functionality; use static binaries for full features
- Pass `verbose=True` to debug issues
