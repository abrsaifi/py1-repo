## 💬 Common Questions

**Q: Where do I access the dashboard?**
A: http://localhost:5000 (make sure server is running: `python server.py`)

**Q: How do I save my settings?**
A: Click "Save" button in Advanced tab, give it a name

**Q: Can I download my settings?**
A: Yes, click "Export" to download as JSON file

**Q: How do I restore downloaded settings?**
A: Click "Import" and select the JSON file

**Q: Will my custom presets be saved?**
A: Yes, they're saved in browser localStorage and survive refresh

**Q: How do I reset everything?**
A: Click "Reset" button in Advanced tab (asks for confirmation)

**Q: What's the difference between Basic and Advanced tabs?**
A: Basic has common settings, Advanced has all settings + search/reset/save/export/import

**Q: How do I search for a parameter?**
A: Click Advanced tab, type in search box (real-time filtering)

**Q: Can I add new tools?**
A: Yes, see [DEVELOPER_GUIDE.md](DEVELOPER_GUIDE.md)

**Q: What comes after Phase 2?**
A: See [PHASE_3_ROADMAP.md](PHASE_3_ROADMAP.md) for optional features
