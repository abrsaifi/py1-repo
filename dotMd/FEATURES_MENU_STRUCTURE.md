## 1. CORE PDF TOOLS

### Essential PDF Operations
- **PDF to B&W** - Convert PDF to Black & White
  - DPI, Threshold, Contrast, Sharpness, Brightness, Gamma controls
  
- **To PDF / Convert to PDF** - Convert various formats to PDF
  - From: Images, Documents, Web pages
  
- **Extract / Smart Extract** - Extract specific pages from PDF
  - Extract by page numbers (e.g., "1-5,7,9")
  
- **Split PDF** - Split PDF into individual pages
  - One PDF per page output
  
- **Merge PDF** - Combine multiple PDFs
  - Up to 50 files support
  
- **Remove Pages** - Delete specific pages from PDF
  - Simple page number removal
  
- **OCR / Advanced OCR** - Extract text from PDF
  - 80+ languages support, searchable output
  
- **Watermark / Add Watermark** - Add text/image watermark
  - Position, opacity, and text customization
  
- **Clean PDF** - Remove metadata & optimize
  - Auto-format cleaning, compression levels
  
- **PDF Compress** - Reduce file size
  - Quality level control (1-100)
  
- **Encrypt PDF** - Protect with password
  - AES encryption support
  
- **Decrypt PDF** - Remove password protection
  - Simple decryption
  
- **Redact Content** - Permanently remove sensitive text
  - Irreversible text removal
  
- **Metadata** - View, Extract, or Remove metadata
  - JSON output or metadata-free PDF
