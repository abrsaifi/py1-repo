## 🎯 New Features at a Glance

### 1️⃣ Help Tooltips - Understand Every Parameter

**What It Is**: Hover over the "?" icon next to any parameter to see what it does

**How to Use**:
1. Go to **Advanced tab**
2. Look for **"?"** icons next to parameter names
3. **Hover** over the "?" to see the explanation
4. Mouse away to hide the tooltip

**Example**:
```
Orientation ? ← Hover here
|            
└─ "Choose page orientation: Portrait is 8.5x11", 
    Landscape is 11x8.5""
```

**Who It Helps**: New users learning the system

---

### 2️⃣ Recently Used Presets - Quick Access

**What It Is**: Your 5 most recently used presets appear at the top of the Presets tab

**How to Use**:
1. Go to **Presets tab**
2. Look for **"RECENTLY USED"** section at the top
3. See presets with **"Last used: 2h ago"** timestamps
4. Click **Apply** to use that preset again

**Example**:
```
RECENTLY USED
─────────────
Standard Portrait
Last used: Just now
[Apply]

Landscape Wide
Last used: 5m ago
[Apply]
```

**Who It Helps**: Regular users working with favorite presets

---

### 3️⃣ Keyboard Shortcuts - Power User Speed

**What It Is**: Quick key combinations to perform common actions instantly

**Shortcuts**:
| Press This | What It Does |
|-----------|------------- |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> | Open "Save Preset" dialog |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | Download settings as file |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>I</kbd> | Load settings from file |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>R</kbd> | Reset all to defaults |
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | Focus on parameter search |
| <kbd>Escape</kbd> | Close any open dialog |

**How to Use**:
1. Make sure the dashboard is in focus
2. Press the keyboard shortcut
3. See notification: "Keyboard shortcut: Ctrl+Shift+S (Save preset)"
4. Dialog/action appears

**Who It Helps**: Advanced users who want to work faster

---

### 4️⃣ Preset Descriptions - Document Your Presets

**What It Is**: Add a note/description when saving a custom preset

**How to Use**:
1. Click **"Save"** button in Advanced tab
2. Enter **preset name** (e.g., "My Reports")
3. Type **optional description** (e.g., "For monthly finance reports")
4. Click **"Save Preset"**

**Example**:
```
Save as Custom Preset
─────────────────────
Preset Name: My Reports
Description: For monthly financial reports with gridlines
             and 2-day aging color coding

[Cancel] [Save Preset]
```

**Benefits**:
- Remember why you created the preset
- See description on preset card
- Organize presets better

**Who It Helps**: Users with many custom presets

---

### 5️⃣ Collapse/Expand Groups - Cleaner Interface

**What It Is**: Hide parameter groups you're not using to reduce clutter

**How to Use**:
1. Go to **Advanced tab**
2. Look for **group headers**: 📐 Layout, 📄 Content, 📦 Output, ⚙️ Advanced
3. Click on the **header** (or the **▼** chevron)
4. Group **collapses smoothly**
5. Click again to **expand**

**Example**:
```
Before:
📐 Layout ▼
  Orientation: [portrait]
  Paper Size: [A4]
  Margins: 20, 20, 20, 20
📄 Content ▼
  Include Headers: ☑
  Gridlines: ☐
  Scale: 100%

After (Content collapsed):
📐 Layout ▼
  Orientation: [portrait]
  Paper Size: [A4]
  Margins: 20, 20, 20, 20
📄 Content ▶    ← Click to expand
```

**Benefits**:
- See only what you need
- Reduce scrolling on mobile
- Focus on relevant settings

**Who It Helps**: Mobile users and those with many parameters

## 💡 Pro Tips

### Tip 1: Speed Workflow with Shortcuts
- **Save quickly**: Ctrl+Shift+S instead of clicking buttons
- **Export immediately**: Ctrl+Shift+E to download
- **Reset easily**: Ctrl+Shift+R instead of scrolling

### Tip 2: Use Recently Used for Repetitive Work
- Apply same preset 5+ times per session?
- It appears in "Recently Used" automatically
- Click once instead of scrolling

### Tip 3: Document Your Presets
- Save descriptions when creating presets
- "Marketing Export" + "Web size, no headers"
- Later: remember exactly what it does

### Tip 4: Collapse to Focus
- Working with margins? Collapse other groups
- Search for a parameter? Collapse non-matching groups
- Mobile user? Collapse all but current group

### Tip 5: Combine Features
1. Use **search** (Ctrl+F) to find parameter
2. **Collapse** unrelated groups
3. **Collapse tooltip** to understand what it does
4. **Save with description** when done

## 🔍 Search Tips (Bonus!)

**Find Parameters Fast**:
- Press **Ctrl+F** to focus search box
- Type **"margin"** → shows only margin parameters
- Type **"grid"** → shows gridlines and grid parameters
- Type **"color"** → shows color-related settings
- **Clear search** → see all parameters again

## ❓ FAQ

**Q: Where are the help tooltips?**
A: Look for "?" icons next to parameter names in Advanced tab. Hover over them.

**Q: Why isn't "Recently Used" showing?**
A: You need to apply at least one preset first. It tracks your selections.

**Q: How do I use keyboard shortcuts on Mac?**
A: Same shortcuts work! Use ⌘+Shift instead of Ctrl+Shift if needed.

**Q: Can I edit descriptions later?**
A: Currently descriptions can't be edited - delete and re-create the preset to change.

**Q: Will my collapse state be saved?**
A: Yes! Each category remembers if you collapsed it. Persists across sessions.
