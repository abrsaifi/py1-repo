# Quick Start Guide: Document Processing System

**15-Minute Setup** | **No Technical Knowledge Required**

---

## 🚀 Get Started in 5 Steps

### Step 1: Access the Dashboard (1 minute)

1. **Open your browser**
2. **Go to**: `https://your-domain.com/dashboard`
3. **Login** with your credentials

### Step 2: Choose Your Task (1 minute)

The dashboard has 5 tabs at the top:

```
[Batch Images] [Batch PDFs] [Smart Crop] [PDF Form Fill] [Export Data]
```

**Pick the one matching your task:**

| If you want to... | Click... |
|-------------------|----------|
| Make photos smaller | **Batch Images** |
| Protect/optimize PDFs | **Batch PDFs** |
| Remove white space from photo | **Smart Crop** |
| Fill out a form automatically | **PDF Form Fill** |
| Convert data to PDF/Excel | **Export Data** |

### Step 3: Upload Your File(s) (2 minutes)

1. **Click the file upload area** (usually a box with upload icon)
2. **Select file(s)** from your computer
3. **Wait for upload** (shows progress bar)
4. **See preview** (some features show preview)

### Step 4: Choose Options (1 minute)

For **Batch Images** or **Batch PDFs**:
- Select the operation you want
- Adjust any settings (quality, size, etc.)

For **Smart Crop**:
- Choose crop mode (usually default is fine)

For **PDF Form Fill**:
- Paste form data (provided as template)

For **Export Data**:
- Choose PDF or Excel output

### Step 5: Process & Download (Free time - comes automatically!)

1. **Click "Process"** (or similar button)
2. **Status bar** shows progress
3. **Green checkmark** = Done!
4. **Click "Download"** to save results

## ❓ FAQ Quick Reference

### General

**Q: Is my data safe?**  
✅ **Yes!** Data is encrypted and deleted immediately after processing.

**Q: How much does it cost?**  
💰 Check your plan. Free tier available for up to 10 files/month.

**Q: How many files can I upload?**  
📁 Up to 50 files per batch recommended. Can do more in separate batches.

### Specific Features

**Q: Batch Images isn't making files smaller**  
→ Try "Compress" instead of "Resize"  
→ Lower quality slider (80 vs 95)

**Q: Smart Crop removed important part of image**  
→ Try different crop mode  
→ Use "Content Detection" first

**Q: PDF Form Fill says "Field not found"**  
→ Check spelling of field names  
→ PDF must be fillable (test in Adobe Reader)

**Q: Downloads aren't working**  
→ Check popup blocker is disabled  
→ Try different browser  
→ Clear cache: Ctrl+Shift+Delete

### Troubleshooting

**Something isn't working?**

1. **Refresh the page** (Ctrl+F5)
2. **Clear browser cache** (Ctrl+Shift+Delete)
3. **Try different browser** (Chrome, Firefox, Safari)
4. **Check internet connection**
5. **Email support**: support@company.com
